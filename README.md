# 🌱 The Green Spoon - Vegan Restaurant Website

Welcome to **The Green Spoon**, a fully responsive and dynamic web platform designed for a modern vegan restaurant. This website showcases the restaurant's philosophy, menu, ordering system, and customer interaction features in a clean, elegant interface.

## 🚀 Live Demo

[🔗 View Live Site](https://the-green-spoon-byf.vercel.app/) &nbsp;

---

## 📌 Features

- 🍽️ **Dynamic Menu** – Categorized vegan dishes with images, prices, and descriptions.
- 🛒 **Online Ordering System** – Customers can place orders directly through the website.
- 📦 **Order Confirmation Page** – A highly professional confirmation interface for placed orders.
- 💬 **Testimonials Section** – Displays real feedback from satisfied customers.
- 📍 **Responsive Design** – Fully mobile-friendly and optimized for all devices.
- ✉️ **Contact Form** – For reservations, inquiries, and feedback.
